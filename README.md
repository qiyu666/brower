# Qiyu Browser

一款基于 WebView 的轻量级 Android 浏览器，在 WebView 限制内尽可能还原 Chrome 的交互体验，使用 Jetpack Compose 构建。

## 功能

### 核心浏览

- **多标签管理** — 无限制开标签，随时切换、关闭
- **标签切换器** — 2 列卡片布局，显示网页缩略图 + 网站 favicon + 域名，当前标签蓝色边框
- **新标签页** — 原生 Compose 页面，搜索框 + 浏览器图标 + 最近访问站点
- **地址栏** — 键盘回车直接提交，无多余按钮；域名（如 `github.com`、`baidu.com/x`）自动识别为 URL，含空格自动搜索；搜索联想（本地历史 + 搜索引擎 suggest）
- **下拉刷新** — 页面滚到最顶部时才触发，中间滚动不会误触
- **内存优化** — 切走标签自动 `onPause` 释放后台 WebView 内存，切回恢复

### 隐私与安全

- **隐私模式** — 无痕标签禁用 DOM 存储和数据库，关闭时自动清除访问域名的 cookies
- **拦截弹窗** — 设置中可开关
- **自动播放控制** — 视频自动播放开关

### 外观与定制

- **深色模式** — 跟随系统 / 浅色 / 深色
- **字号调节** — 75% ~ 150%
- **桌面模式** — 切换为桌面版 Chrome UA，显示桌面版网页
- **多搜索引擎** — Google / Bing / DuckDuckGo / Baidu

### 工具

- **扫码** — 二维码 + 一维条码（EAN/UPC/Code 128/39/93 等），支持手电筒开关
- **流量统计** — 菜单「流量」查看当前页已加载与会话累计流量
- **页面缩放** — 菜单底部横向滑杆（50%~200% 实时拖动）+ 页面双指缩放
- **桌面小组件** — 常用网址 4×2 快捷方式（长按桌面 → 小组件添加）

### 下载与数据

- **自定义下载目录** — 预设（默认 / 图片 / 视频 / 音乐）或任意目录（SAF 选择器）
- **下载管理** — 进度条、暂停、重试；失败/取消的 HTTP 下载可一键重试；支持清空全部记录；前台服务保证后台继续下载
- **完成项操作** — 「用其他应用打开」「显示在文件夹中」
- **页面资源下载** — 支持 blob / data URL（如音乐站点“下载 MP3”），文件名自动从页面元素捕获；通知栏常驻显示进度可点进下载页，应用内 Toast 提示开始 / 完成 / 失败
- **书签** — 收藏网页，支持文件夹（新建 / 嵌套 / 删除）
- **浏览历史** — 按天分组、搜索、单条删除、按时段清除（今天 / 昨天 / 1 天 / 7 天 / 1 个月）
- **一键清理** — 菜单「清理数据」按勾选清除 浏览历史 / Cookie 与站点数据 / 缓存

### 界面

- **启动闪屏** — 深色底 + 应用图标（渐变环 + qiyu），无空白闪屏
- **底部导航** — Chrome 风格：后退 / 前进 / 新标签 / 标签数 / 菜单
- **溢出菜单** — 底部抽屉式，图标网格布局（仿 Chrome），含 书签/历史/下载、私密/设置/开发者/分享、流量/扫码/清理数据，底部为缩放滑杆
- **中英双语** — 完整 i18n 支持，首次启动自动识别系统语言（中文 / 英文）

### 开发者面板

- **网络记录** — 主文档（状态码 + 大小）与子资源请求流水（环形缓冲 300 条，4xx/5xx 标红）
- **控制台** — 页面 `console.log/warn/error` 实时收集，带来源，等宽字体
- **远程调试** — 开关后电脑 Chrome 打开 `chrome://inspect` 连上本应用 WebView，使用完整 DevTools

### 更新与安装

- **手动检查更新** — 设置页“版本”行检查最新版，一键下载（直连失败自动切 gh-proxy 代理）
- **安装权限引导** — 安装前自动发起安装请求；未授予「安装未知应用」权限时引导去设置页，授权返回后自动继续安装
- **国内 ROM 适配** — 小米/红米等 ROM 安装请求直通系统应用包安装器（系统界面点“继续”即可）；被拦截时 APK 自动存入 Download 目录，可用文件管理器安装
- **崩溃日志回收** — 闪退自动重启并把完整堆栈复制到剪贴板，方便反馈定位

## 技术栈

| 层 | 技术 |
|---|---|
| UI | Jetpack Compose (Material3) |
| 语言 | Kotlin |
| 数据 | Room + Kotlin Coroutines/Flow |
| 最低版本 | Android 8.0 (API 26) |
| 目标版本 | Android 14 (API 34) |

## 安装

### 从 Release 下载

前往 [Releases](https://github.com/qiyu666/brower/releases) 下载最新 APK，直接安装。

### 从源码构建

```bash
# 需要 Android SDK + JDK 17
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

或使用 GitHub Actions 自动构建（见 `.github/workflows/build-apk.yml`）。
